# Cross-browser release status

The extension has separate production builds for Chrome/Brave, Edge, and Firefox. The maintainer reports successful live operation in Chrome, Brave, Edge, and Firefox. Edge Add-ons is in review, and Firefox AMO is awaiting review; store-installed update behavior remains to be tested after approval.

## Build outputs

Run from the repository root after `npm ci` and after configuring the ignored production `.env.local` from `.env.example`:

```powershell
npm run build
npm run build:edge
npm run build:firefox
```

- `dist/` is the production Chrome/Brave package.
- `dist-edge/` is the Edge Add-ons package. Its build strips `manifest.key` because Partner Center rejects that field; the Edge store assigns the listing identity.
- `dist-firefox/` is the Firefox MV3 package. It uses a bundled classic background script, Gecko ID `codeforces-github-sync@forrealtho`, Firefox data-collection declarations, Firefox 142+ minimum version, and no Chromium manifest key.

Load the corresponding directory unpacked for local testing. Browser profiles retain separate vaults and history. The maintainer reports live OAuth and sync testing in all four browsers; this report is not a substitute for store validation or store-installed tests.

## Store package generation

Run:

```powershell
npm run build:edge
npm run build:firefox
./scripts/package-browser-stores.ps1
```

This produces Edge and Firefox runtime ZIPs plus a Firefox source-code ZIP in the ignored `outputs/store-submissions-v0.2.0-edge-keyfix/` directory. The browser package ZIPs have `manifest.json` at their root. The script refuses to overwrite existing files and excludes listing-only artwork from the runtime ZIPs. For submission details, listing copy, artwork, reviewer notes, and remaining manual checks, see [Store submission guide](STORE_SUBMISSION.md).

The Firefox package is not signed by this project. Upload the ZIP to AMO for validation and signing; AMO requires source code and build instructions when code is bundled or transformed. Submit the matching source ZIP generated by the same script.
