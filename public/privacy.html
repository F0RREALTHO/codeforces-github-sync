Privacy policy

Last updated October 25, 2026 · Version 0.2.0

Codeforces → GitHub Sync is a browser extension that helps you copy Accepted Codeforces solutions to a GitHub repository you select.

Information the extension handles

  • Codeforces account and submissions: your handle and API key are used for Codeforces API requests. Your API secret is used locally to sign requests. The extension also processes submission IDs, contest and problem details, programming language, rating and tags when available, submission time, verdict, and source returned by Codeforces.
  • GitHub account and repository: GitHub provides your account name and repository information. The extension handles OAuth access and refresh tokens, the selected repository, sync status, generated file paths, and GitHub file SHAs used to verify files the extension previously wrote.
  • Preferences and history: the extension stores sync settings, filters, progress checkpoints, and compact history entries such as submission and problem metadata, outcome, timestamp, and file path. The history ledger does not store complete solution source code.

How information is used and shared

The extension sends signed requests from your browser to the Codeforces API to verify a handle and read submission history, including source when Codeforces returns it. The API key and request signature are sent to Codeforces; the API secret is used to create the signature and is not included in the request.

When syncing, the extension sends the selected Accepted solution source and associated problem metadata from your browser to the GitHub API. It can list repositories available to the authorized account, create a repository if you choose that option, read existing files to check ownership, and create or update generated solution files. When a tracked solution changes its file extension, the extension may remove the previous tracked file after successfully writing its replacement. It does not intentionally modify unrelated repository files.

GitHub sign-in uses a GitHub App and OAuth with PKCE. The extension sends the authorization code and PKCE verifier to the project's Cloudflare Worker, which uses the GitHub App client secret held in its Worker environment to exchange them with GitHub and return token data. The Worker also forwards refresh-token requests to GitHub and returns rotated tokens. The Worker processes OAuth data but is not sent Codeforces solution source or GitHub repository file contents. The Worker code does not configure a database for these requests; this policy does not make claims about hosting-provider operational logs or retention.

The GitHub App is installed for the repositories you authorize. Its configured permissions include repository metadata read access and repository contents read/write access; repository creation is used if you choose to create a repository from the extension. GitHub displays the app's permissions and repository access during authorization and installation.

Local storage and credential protection

Codeforces credentials and GitHub tokens are stored in the browser's extension-local storage as ciphertext encrypted with AES-256-GCM. The encryption key is derived from your vault password using PBKDF2-SHA-256. While the vault is unlocked, the key is held in Chrome's session storage and is restricted to trusted extension contexts. The session storage key is not a separate hardware-backed security boundary: browser or extension compromise while unlocked may expose data available to the extension.

Settings and sync checkpoints are stored in extension-local storage. Compact sync history and repository ownership records are stored in IndexedDB in the browser profile. Ownership records contain repository and account identifiers, generated file paths, submission IDs, and file SHAs; they contain neither solution source nor credentials. These records let the extension verify a previously written file by comparing its current GitHub SHA with the locally saved ownership record.

Retention and your controls

The extension does not set a time-based retention period or automatically expire sync-history and ownership records. Those records remain in the browser profile across account disconnects and vault resets until you clear the extension's browser data or remove the extension. Removing an account clears that provider's locally stored credentials and connection settings; it does not delete committed GitHub files, erase the persistent history and ownership ledger, or uninstall/revoke the GitHub App. You can revoke the app separately in GitHub settings and remove synced files from the repository yourself.

You can pause sync, disable automatic sync, disconnect either account, lock or reset the credential vault, and clear the extension's browser data. After a browser restart, the vault must be unlocked again with its password. If you forget that password, the extension cannot recover it; resetting the vault removes stored credentials and you must reconnect your accounts.

Analytics and advertising

The extension contains no analytics or advertising feature and does not intentionally send usage telemetry. Information is handled to provide the Codeforces-to-GitHub synchronization features described above.
